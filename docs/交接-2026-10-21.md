## 1 本轮（2026-10-20 ~ 10-21）做了什么

### 1.1 收敛判据（`9c3df9f` + 文档 `bafa87f`）

- **问题**：L4 基线里 `defects` 三次全撞 12 轮上限、提交 4/7/8 条；总截断 6/12。根因不是模型笨，是系统指令没定义「查到什么时候算够」。
- **改法**：`src/agent/shared/prompt.ts` 新增三条收尾判据（计划覆盖完 / 提交满 8 条后只能写总结 / 连续两次无新线索）+ 禁止凑步数 + 越界请求处理；`knowledge/eval/agent-queries.json` 把 `defects` 窗口 12 → 14（算术写在该文件里：8 条 × 一条一轮 + 准备 5–6 轮 + 收尾 1 轮 = 13–15 轮）。
- **实测**（同机连跑三次）：截断 6/12 → **3/12**；`defects` 提交 **7/8/8**、三次自然收尾；工具成功率 95.7% → **99.0%**；平均轮次 7.17 → 7.58（**没有下降** —— 提交条数变多，而 `submit_issue` 一次只能提交一条）。
- **如实写进文档的残余**：提示词只能决定「何时停」，决定不了「一条一轮」的成本；越界请求仍会继续查质量。→ 登记为 **T11**（批量提交 / 满 8 条自动停止），**属产品行为改动，需所有者拍板**，不要擅自做。

### 1.2 SSE 带 usage，真实成本可测（`c4ac92b` + 文档 `da89648`）

- **改法**：`src/app/api/agent/route.ts` 在 `finish` 时把 `totalUsage` 随消息元数据带回；供应商没给时字段为 undefined、**不填 0**（0 会被读成「不花钱」）。L4 评测从 finish 块读 usage、跨轮累加，读不到显示「未测到」。
- **实测**（12 次对话，91/91 轮上报）：输入 **684,554** / 输出 **27,247** token，**单次分析 ≈ ¥0.13**（输入 ¥2/百万、输出 ¥8/百万，单价硬编码在 `agentEval.test.ts`）。
- **最值得记住的结论**：比早期按「结构摘要 2674 token」估的 ¥0.02 高 **约 6 倍**——平均 7.6 轮，每轮都把累积会话历史重新发一遍。**「只发摘要」在隐私上成立，但推不出「成本低」；轮次才是成本主因**，T11 同时也是成本优化。
- 评测入口：`pnpm dev`（另开）→ `pnpm eval:agent`（约 4–6 分钟，会产生约 ¥1.6 API 费用）。

### 1.3 `/api/agent` 实例级限流（`86fd8c3` + 文档 `46ac0c8`）

- **为什么**：公开演示地址 + 无鉴权 = 任何人都能烧掉模型配额，且没有告警。
- **改法**：`src/agent/server/rateLimit.ts`（固定窗口、按访客计数、时间可注入、条目数上限+过期清理）；默认 **240 次 / 5 分钟 / 访客**（`AGENT_RATE_LIMIT_MAX` / `AGENT_RATE_LIMIT_WINDOW_MS` 可调）；访客键 `x-forwarded-for` 第一段 → `x-real-ip` → `unknown`；被拒 **429 + `Retry-After` + 中文**（「这是演示站防止配额被单个访客耗尽，**不是模型服务出错**」）；`normalizeLlmError` 专门分支排在供应商 429 之前，避免用户去等模型恢复。
- **做不到什么（代码注释与技术文档 §8.2 都写清了）**：内存计数只在当前实例有效，Serverless 多实例各算各的、冷启动清零 —— 这是**防误刷，不是硬配额**；也**没有鉴权**，换来源即可绕过。

### 4.2 已知坑（都踩过，别重踩）

- **GitHub 网络极不稳定**：`schannel` 握手失败、TCP 超时、`Empty reply`、`Connection reset` 都是线路问题，**不是凭据**。用下面的重试循环，10–60 次通常能成；两个推送进程同时跑会互相 `[remote rejected]`，看到「Everything up-to-date」或远端 hash 已更新即成功。
  ```powershell
  function Test-GitHub { $c = New-Object System.Net.Sockets.TcpClient
    try { $t = $c.ConnectAsync('github.com',443); if ($t.Wait(5000)) { return $c.Connected }; return $false }
    catch { return $false } finally { $c.Close() } }
  for ($i=1; $i -le 60; $i++) { if (Test-GitHub) { git push origin main 2>&1 | Out-String; if ($LASTEXITCODE -eq 0) { "OK $i"; break } }; Start-Sleep -Seconds 10 }
  ```
- **并行会话**：本项目还有另一个会话在写 `docs/部署指南`（未跟踪的 `docs/部署指南.docx` 是它的产物，**不要提交**）。动手前先 `git status` + `git log -3`；提交前确认没覆盖别人的改动。
